この **Manta Businesses Dataset Sample** には **1,547件のレコード** が含まれており、**Bright Data API** を使用して抽出されました。

## Data Points

| Field Name | Description |
|------------|-------------|
| `company_name` | 事業体の正式名称です。 |
| `business_state` | 事業が登録されている、または運営されている州です。 |
| `sic_code` | 事業種別を示す Standard Industrial Classification コードです。 |
| `phone_number` | 事業の連絡先電話番号です。 |
| `website` | 事業の公式WebサイトURLです。 |
| `business_categories` | 事業活動および業界を定義するカテゴリです。 |
| `business_city` | 事業が所在する市区町村です。 |
| `business_country` | 事業が所在する国です。 |
| `business_zip_code` | 事業所在地の郵便番号です。 |
| `closed_on` | 該当する場合、事業が閉業しているかどうかを示します。 |
| `opening_hours` | 事業の開店時刻です。 |
| `closing_hours` | 事業の閉店時刻です。 |
| `latitude` | 事業所在地の地理的緯度座標です。 |
| `longitude` | 事業所在地の地理的経度座標です。 |
| `location_type` | 事業所在地の種類（例：小売、オフィス）です。 |
| `year_established` | 事業が設立された年です。 |
| `avg_opening_hour` | 通常の開店時刻（時）の日平均です。 |
| `avg_closing_hour` | 通常の閉店時刻（時）の日平均です。 |
| `business_street_name` | 事業所在地の住所（通り名）です。 |
| `description` | 事業およびその運営に関する簡単な概要です。 |
| `services` | 事業が提供するサービスの一覧です。 |
| `links` | 該当する場合、事業に関連する追加リンクです。 |
| `estimated_annual_revenue` | 事業が生み出す推定年間収益です。 |
| `num_employees` | 事業で働く従業員数です。 |
| `review_count` | 事業が受け取ったレビュー総数です。 |
| `reviews` | 事業に関する顧客レビューおよびフィードバックです。 |
| `owner` | 事業オーナーまたは主要連絡先の氏名です。 |
| `manta_link` | Mantaプラットフォーム上の事業プロフィールへのURLです。 |
| `url` | 事業に関連する一般的なURLです。 |
| `company_id` | データセット内における事業の一意識別子です。 |


## Use Cases

### 1. Market Analysis
データセットを活用して市場動向や業界ベンチマークを特定し、戦略立案および意思決定に役立てます。

### 2. Business Development
事業詳細を活用して潜在的なパートナーや顧客を発見し、ネットワーキングと成長機会を強化します。

### 3. Competitive Intelligence
競合情報を分析して運営状況や市場でのポジショニングに関する洞察を得ることで、競争戦略を改善します。

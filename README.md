この**Manta Businesses Dataset Sample**には**1,547件のレコード**が含まれており、**Bright Data API**を使用して抽出されました。

## Data Points

| Field Name | Description |
|------------|-------------|
| `company_name` | 事業体の正式名称。 |
| `business_state` | 事業が登録または運営されている州。 |
| `sic_code` | 事業の種類を示すStandard Industrial Classificationコード。 |
| `phone_number` | 事業の連絡先電話番号。 |
| `website` | 事業の公式WebサイトURL。 |
| `business_categories` | 事業活動および業種を定義するカテゴリ。 |
| `business_city` | 事業が所在する市区町村。 |
| `business_country` | 事業が所在する国。 |
| `business_zip_code` | 事業所在地の郵便番号。 |
| `closed_on` | 該当する場合、事業が閉業しているかどうかを示します。 |
| `opening_hours` | 事業の開店時刻。 |
| `closing_hours` | 事業の閉店時刻。 |
| `latitude` | 事業所在地の地理的な緯度座標。 |
| `longitude` | 事業所在地の地理的な経度座標。 |
| `location_type` | 事業所在地の種類（例: retail、office）。 |
| `year_established` | 事業の設立年。 |
| `avg_opening_hour` | 事業が通常開店する1日の平均時刻。 |
| `avg_closing_hour` | 事業が通常閉店する1日の平均時刻。 |
| `business_street_name` | 事業所在地の住所。 |
| `description` | 事業およびその運営に関する簡単な概要。 |
| `services` | 事業が提供するサービスの一覧。 |
| `links` | 該当する場合、事業に関連付けられた追加リンク。 |
| `estimated_annual_revenue` | 事業が生み出す年間売上高のおおよその額。 |
| `num_employees` | 事業で働く従業員数。 |
| `review_count` | 事業が受け取ったレビューの総数。 |
| `reviews` | 事業に関する顧客レビューおよびフィードバック。 |
| `owner` | 事業オーナーまたは主要連絡先の名前。 |
| `manta_link` | Mantaプラットフォーム上の事業プロフィールURL。 |
| `url` | 事業に関連する一般的なURL。 |
| `company_id` | データセット内での事業の一意識別子。 |


## Use Cases

### 1. 市場分析
このデータセットを活用して市場トレンドや業界ベンチマークを特定し、戦略立案や意思決定に役立てます。

### 2. 事業開発
事業の詳細情報を活用して潜在的なパートナーや顧客を見つけ、ネットワーキングと成長の機会を強化します。

### 3. 競合インテリジェンス
競合情報を分析してその運営や市場でのポジショニングに関する洞察を得ることで、競争戦略を改善します。
